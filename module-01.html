MODULE 01

🌐 Introduction to Web Development

Understand what websites are, how they work and the basic technologies used to build them.

TOPIC 01

What Is a Website?

A website is a collection of pages and information that people can access through the internet using a web browser.

Websites can be used for many purposes. Businesses use them to show their products and services. Schools use them for learning. Individuals use them for portfolios, blogs and personal projects.

Examples of things you can build include:

  • 💼 Business websites
  • 👤 Personal portfolios
  • 🍽️ Restaurant websites
  • 🛍️ Online stores
  • 🎓 Educational websites
  • 📰 Blogs and information websites

TOPIC 02

How Does a Website Work?

When you open a website, your browser requests information from a web server.

The server sends the website files back to your browser, and the browser displays the website on your screen.

A simple example:

📱 You → 🌐 Internet → 🖥️ Server → 🌐 Website → 📱 You

TOPIC 03

What Is Frontend Development?

Frontend development is the part of website development that creates what visitors see and interact with.

When you look at a website and see its headings, images, buttons, colors and menus, you are looking at the frontend.

The main frontend technologies are:

  • 📝 HTML — Structure
  • 🎨 CSS — Design
  • ⚡ JavaScript — Interaction

TOPIC 04

HTML, CSS and JavaScript

📝 HTML — The Structure

HTML tells the browser what content exists on your page.

For example, HTML can create headings, paragraphs, images, links and forms.

🎨 CSS — The Design

CSS controls how your website looks. It can change colors, fonts, spacing, layouts and animations.

⚡ JavaScript — The Interaction

JavaScript allows your website to respond to actions from the visitor.

For example, JavaScript can make a menu open, display a message or react when someone clicks a button.

TOPIC 05

Frontend vs Backend

You will mainly focus on frontend development in this course.

🌐 Frontend

The part users see and interact with.

🖥️ Backend

The part that works behind the scenes, such as servers, databases and user authentication.

💡 Think of a restaurant:

The dining area is like the frontend.

The kitchen is like the backend.
