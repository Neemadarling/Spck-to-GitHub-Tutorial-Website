LESSON 05

Learn GitHub

Store your website online and prepare it for publishing.

🐙

What is GitHub?

GitHub is a platform where developers can store, manage and collaborate on code projects.

You can use a GitHub repository to keep the files that make up your website.

GitHub Pages can also publish suitable static websites online.

01

Create a GitHub Account

Open GitHub in your phone browser and create an account if you don't already have one. 

https://github.com/

Choose a username that you are comfortable using publicly because your profile and repository names can be visible online.

02

Create a Repository

A repository is a place where your project files are stored.

On GitHub, create a new repository and give it a simple name, for example: 

my-website
💡 Tip: Avoid spaces in repository names. Simple names such as my-website are easier to manage.
03

What Goes Inside Your Repository?

Your website repository can contain files such as: 

my-website/
│
├── index.html
├── about.html
├── tutorials.html
├── spck.html
├── html-tutorial.html
├── css-tutorial.html
├── javascript-tutorial.html
├── github.html
├── style.css
└── script.js

Images and other website assets can also be stored in the repository.

04

What is a Commit?

A commit records a change to your project.

Think of it as saving a version of your work in the project's history. 

Add my first website pages

A good commit message briefly explains what you changed.

05

Upload Your Website Files

You can upload your website files to your GitHub repository using GitHub's web interface or another Git-compatible workflow.

Make sure your main page is named: 

index.html

This is important when publishing a typical static site with GitHub Pages.

06

What is GitHub Pages?

GitHub Pages is a GitHub feature that can publish static website files from a repository.

For a basic HTML, CSS and JavaScript website, it can provide a public web address. 

https://USERNAME.github.io/REPOSITORY/

Your exact URL depends on your GitHub username, repository and Pages configuration.

07

Check Your File Names

Website links are sensitive to exact file names and paths.

For example: 

html-tutorial.html

must match the link in your HTML: 

<a href="html-tutorial.html">
HTML Tutorial
</a>
⚠️ Common mistake: Using HTML-Tutorial.html in one place and html-tutorial.html in another can cause a page not to open, especially on case-sensitive hosting.
08

Check Your CSS and JavaScript

Your HTML pages should point to the correct CSS and JavaScript files. 

<link rel="stylesheet"
      href="style.css">

<script src="script.js">
</script>

If your page looks unstyled or your menu doesn't work after publishing, check these file paths first.

09

Update Your Website

When you change your website in SPCK, you need to update the corresponding files in GitHub before the online version reflects those changes.

A simple workflow is: 

Edit in SPCK
      ↓
Save
      ↓
Test
      ↓
Upload/update on GitHub
      ↓
Wait for GitHub Pages
      ↓
Open your website

PRACTICE

Your GitHub Checklist

  • Create a GitHub account
  • Create a repository
  • Prepare your website files
  • Upload your files
  • Confirm that index.html exists
  • Configure GitHub Pages
  • Open your published website
