MODULE 04

⚡ JavaScript Basics

Learn how to make your website interactive and respond to what visitors do.

TOPIC 01

What Is JavaScript?

JavaScript is a programming language used to add interaction and behavior to websites.

HTML creates the structure, CSS controls the design, and JavaScript can make the website respond to visitors.

📝 HTML = Structure

🎨 CSS = Design

⚡ JavaScript = Interaction

For example, JavaScript can make a button display a message when someone clicks it.

TOPIC 02

Connecting JavaScript to HTML

We normally connect an external JavaScript file to our HTML page using the <script> element. 

<script src="script.js"></script>

This tells the browser to load the JavaScript code from a file called script.js.

In your SPCK project, keep your HTML, CSS and JavaScript files organized.

TOPIC 03

Variables

A variable is a named place where JavaScript can store information. 

let name = "Neema";

let age = 25;

const course = "Web Development";

let is commonly used when a value may change.

const is commonly used when the variable should not be reassigned.

💡 Variable example:

let studentName = "Amina";

The variable studentName stores the text "Amina".

TOPIC 04

JavaScript Data Types

JavaScript can work with different types of information.

Text — String 

let name = "Neema";

Number 

let price = 2500;

Boolean 

let isStudent = true;

Array 

let courses = [
    "HTML",
    "CSS",
    "JavaScript"
];

You will learn more about arrays and objects later in the course.

TOPIC 05

Operators

Operators allow JavaScript to perform calculations and comparisons. 

let total = 100 + 50;

let difference = 100 - 50;

let product = 10 * 5;

let division = 100 / 2;

You can also compare values: 

10 > 5

10 < 20

10 === 10

10 !== 5

TOPIC 06

if and else

JavaScript can make decisions using if and else. 

let age = 20;

if (age >= 18) {

    console.log("You are an adult.");

} else {

    console.log("You are under 18.");

}

The browser checks the condition and runs the appropriate block of code.

TOPIC 07

Functions

A function is a reusable block of code designed to perform a particular task. 

function sayHello() {

    console.log("Hello!");

}

sayHello();

You can call the function whenever you need it.

Function with a parameter 

function greet(name) {

    console.log("Hello " + name);

}

greet("Neema");

TOPIC 08

Events

An event happens when a visitor interacts with a webpage.

Examples include:

  • 🖱️ Clicking a button
  • ⌨️ Typing into an input
  • 📱 Touching an element
  • 🖱️ Moving the mouse

JavaScript can listen for these events and respond to them.

TOPIC 09

Making a Button Interactive

First create a button in HTML: 

<button id="helloButton">
    Click Me
</button>

Then JavaScript can respond to the click: 

const button =
    document.getElementById("helloButton");

button.addEventListener(
    "click",
    function() {

        alert("Hello! Welcome to my website.");

    }
);

Now the button performs an action when the visitor clicks it.

TOPIC 10

Changing Website Content

JavaScript can change HTML content after the webpage has loaded.

HTML: 

<h2 id="message">
    Welcome!
</h2>

JavaScript: 

const message =
    document.getElementById("message");

message.textContent =
    "Welcome to Neema Charo Academy!";

This is one of the most important ideas in beginner JavaScript: JavaScript can interact with HTML.

TOPIC 11

Getting Information From an Input

JavaScript can read information that a visitor enters into a form. 

const nameInput =
    document.getElementById("name");

const name =
    nameInput.value;

This allows you to build interactive forms, calculators, quizzes and other web features.

TOPIC 12

Console.log()

The console is a useful place to test and debug JavaScript. 

console.log("Hello World!");

console.log(10 + 20);

When you open your browser's developer tools, you can see these messages in the console.

COMPLETE EXAMPLE

Simple Interactive JavaScript Project

HTML 

<input
    id="nameInput"
    type="text"
    placeholder="Enter your name">

<button id="welcomeButton">
    Say Hello
</button>

<p id="message"></p>

JavaScript 

const input =
    document.getElementById("nameInput");

const button =
    document.getElementById("welcomeButton");

const message =
    document.getElementById("message");


button.addEventListener(
    "click",
    function() {

        const name = input.value.trim();

        if (name === "") {

            message.textContent =
                "Please enter your name.";

            return;

        }

        message.textContent =
            "Hello " + name +
            "! Welcome to Neema Charo Academy.";

    }
);

This small project demonstrates several important JavaScript skills:

  • Selecting HTML elements
  • Reading input values
  • Responding to a click
  • Using a condition
  • Changing webpage content
