MODULE 05

📦 JavaScript Arrays & Objects

Learn how to organize and work with multiple pieces of information in JavaScript.

TOPIC 01

What Is an Array?

An array is a JavaScript structure used to store multiple values in one variable. 

let fruits = [
    "Mango",
    "Banana",
    "Orange"
];

Instead of creating a separate variable for every fruit, we can keep them together in an array.

TOPIC 02

Accessing Array Items

JavaScript uses an index to access items in an array. The first item starts at index 0. 

let fruits = [
    "Mango",
    "Banana",
    "Orange"
];

console.log(fruits[0]);

console.log(fruits[1]);

The first example displays Mango and the second displays Banana.

TOPIC 03

Adding Items to an Array

let courses = [
    "HTML",
    "CSS"
];

courses.push("JavaScript");

console.log(courses);

The push() method adds an item to the end of an array.

TOPIC 04

Removing Items

let courses = [
    "HTML",
    "CSS",
    "JavaScript"
];

courses.pop();

console.log(courses);

The pop() method removes the last item.

TOPIC 05

Array Length

let courses = [
    "HTML",
    "CSS",
    "JavaScript"
];

console.log(courses.length);

The length property tells you how many items are inside an array.

TOPIC 06

What Is an Object?

An object stores related information using properties and values. 

let student = {

    name: "Amina",

    age: 22,

    course: "Web Development"

};

TOPIC 07

Accessing Object Information

console.log(student.name);

console.log(student.course);

You can access an object's property using a dot.

TOPIC 08

Changing Object Information

student.age = 23;

console.log(student.age);

TOPIC 09

Arrays of Objects

Real websites often need to work with lists of objects. 

let students = [

    {
        name: "Amina",
        course: "HTML"
    },

    {
        name: "Brian",
        course: "CSS"
    },

    {
        name: "Jane",
        course: "JavaScript"
    }

];
