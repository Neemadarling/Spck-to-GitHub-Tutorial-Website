MODULE 11

🚀 Publish Your Website

Take your website from your phone to the internet.

TOPIC 01

Prepare Your Website

Before publishing, check every page carefully.

  • Check spelling.
  • Check links.
  • Check images.
  • Check mobile design.
  • Check JavaScript.
  • Remove unnecessary files.

TOPIC 02

Check Your Homepage

Your website should have: 

index.html

This is normally the entry page for a static website.

TOPIC 03

Enable GitHub Pages

Open your GitHub repository and go to its Pages settings. Choose the branch and folder containing your website, then save the configuration.

TOPIC 04

Find Your Website Link

After GitHub Pages finishes publishing, GitHub provides a public website address.

Open that address and test your website.

TOPIC 05

Test Your Published Website

Test:

  • Home page
  • Navigation
  • Buttons
  • Images
  • Contact links
  • Mobile layout

TOPIC 06

Updating Your Website

When you make changes, update the files in your GitHub repository and wait for the published site to rebuild.

Always test the live website after important changes.

PRACTICAL PROJECT

🚀 Publish Your Own Website

Publish the website you have been building throughout this course.

Then send your website link to a friend or potential client and ask them to test it.

MODULE 11 EXERCISE

🧠 Final Publishing Checklist

  1. Does your homepage open?
  2. Do all navigation links work?
  3. Do your images load?
  4. Does your website work on a phone?
  5. Does your live link open?
  6. Can another person visit it?

🎉 Module 11 Complete!

Congratulations! Your website can now be available online.
