MODULE 07

📱 Build a Website Using Your Phone

Learn how to create and manage a real website using SPCK Editor on your phone.

TOPIC 01

What Is SPCK?

SPCK Editor is a mobile coding environment that allows you to create and edit website files from your phone.

You can work with HTML, CSS and JavaScript without needing a computer for basic website development.

TOPIC 02

Create Your Project

Open SPCK and create a new project.

Your project can contain files such as: 

index.html
style.css
script.js

TOPIC 03

Understand Your Files

HTML contains the structure.

CSS controls the design.

JavaScript adds interaction.

TOPIC 04

Preview Your Website

Save your files and use the preview option in SPCK to see your website.

Always check your website after making important changes.

TOPIC 05

Organize Your Project

Keep your files clearly named. 

website/
│
├── index.html
├── about.html
├── contact.html
├── style.css
├── script.js
│
└── images/

TOPIC 06

Common Mistakes

  • Incorrect file names
  • Missing closing HTML tags
  • Incorrect CSS file path
  • Incorrect JavaScript file path
  • Forgetting to save files
  • Broken image paths

🛠️ Build a Website on Your Phone

  • Home page
  • About page
  • Contact page

Connect all pages using navigation links.
