LESSON 04

JavaScript for Beginners

Learn how to make your website interactive.

⚡

What is JavaScript?

JavaScript is a programming language commonly used to add interaction and behavior to websites.

HTML creates the structure, CSS controls the appearance, and JavaScript can make the page respond to actions.

For example, JavaScript can control menus, buttons, popups, counters and interactive forms.

01

Create Your JavaScript File

In SPCK create: 

script.js

Then connect it to your HTML before the closing </body> tag: 

<script src="script.js"></script>
02

Display a Message

One simple way to test JavaScript is: 

alert("Hello from Neema Charo!");

When the page loads, the browser can display a message.

💡 Tip: Remove or comment out test alerts when you don't want them appearing every time the page loads.
03

Variables

Variables allow you to store information. 

let name = "Neema";

let age = 25;

const website = "Neema Charo Tutorial";

Use let when a value may need to change. Use const for a value that you don't plan to reassign.

04

Functions

A function is a reusable block of code. 

function sayHello() {

    alert("Welcome to my website!");

}

You can call the function when you need it: 

sayHello();
05

Button Clicks

HTML: 

<button id="helloButton">
    Click Me
</button>

JavaScript: 

const button =
    document.getElementById("helloButton");

button.addEventListener("click", function() {

    alert("Hello!");

});
06

Changing HTML with JavaScript

JavaScript can change the content of an HTML element. 

<h2 id="message">
    Original Message
</h2>

Then: 

document.getElementById("message")
    .textContent = "New Message!";
07

Show and Hide Elements

JavaScript can change an element's style. 

const box =
    document.getElementById("box");

box.style.display = "none";

To show it again: 

box.style.display = "block";
08

Toggle a Mobile Menu

A common use of JavaScript is opening and closing a mobile navigation menu. 

function toggleMenu() {

    const menu =
        document.getElementById("navLinks");

    menu.classList.toggle("active");

}

This is the type of interaction used by the menu button on this tutorial website.

09

Simple Counter

You can create a counter using JavaScript. 

let count = 0;

function increase() {

    count++;

    document.getElementById("counter")
        .textContent = count;

}

Connect the function to a button to allow visitors to increase the number.

10

JavaScript and Forms

JavaScript can read information entered into a form and respond to it. 

const nameInput =
    document.getElementById("name");

console.log(nameInput.value);

The value property gives you the information currently entered in the input.

11

Console

The console is useful when testing JavaScript. 

console.log("My website is working!");

On supported browsers, developers can open the browser's developer tools to inspect console messages and errors.

12

JavaScript and Animation

JavaScript can add or remove CSS classes, allowing CSS animations to be triggered by user actions. 

element.classList.add("show");

element.classList.remove("hide");

This is a useful way to combine JavaScript behavior with CSS animation.

MINI PROJECT

Build an Interactive Welcome Button

Create this HTML: 

<h2 id="welcome">
    Welcome!
</h2>

<button id="welcomeButton">
    Say Hello
</button>

Then add this JavaScript: 

const button =
    document.getElementById("welcomeButton");

button.addEventListener("click", function() {

    document.getElementById("welcome")
        .textContent =
        "Hello! Welcome to my website.";

});
