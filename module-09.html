MODULE 09

✨ Animations & Interactive Features

Learn how to make your website feel modern, smooth and interactive.

TOPIC 01

CSS Transitions

.button {

    transition: transform 0.3s ease;

}

.button:hover {

    transform: scale(1.05);

}

Transitions make changes happen smoothly.

TOPIC 02

CSS Animations

@keyframes move {

    from {
        transform: translateY(0);
    }

    to {
        transform: translateY(-10px);
    }

}

.card {

    animation: move 2s infinite alternate;

}

TOPIC 03

Button Interaction

const button =
document.getElementById("button");

button.addEventListener(
"click",
function() {

    alert("Button clicked!");

});

TOPIC 04

Show and Hide Content

const box =
document.getElementById("box");

box.style.display = "none";

box.style.display = "block";

TOPIC 05

Interactive Navigation

JavaScript can be used to open and close mobile menus. 

menuButton.addEventListener(
"click",
function() {

    navLinks.classList.toggle("open");

});

TOPIC 06

Keep Animations Useful

Animations should improve the user experience rather than make the website difficult to use.

  • Keep them simple.
  • Do not animate everything.
  • Make buttons easy to use.
  • Keep mobile users in mind.
