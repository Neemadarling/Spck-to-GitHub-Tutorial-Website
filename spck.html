LESSON 01

Learn SPCK Editor

Your phone can be your first coding workspace.

📱

What is SPCK Editor?

SPCK Editor is a mobile code editor that allows you to create and edit files used to build websites.

Instead of needing a computer to begin learning, you can use your smartphone to practice HTML, CSS and JavaScript.

01

Open SPCK Editor

Install and open SPCK Editor on your Android phone. Once inside the application, create a new project or workspace.

💡 Tip: Keep your project organized from the beginning. Give your project a name that you will easily recognize.
02

Create Your HTML File

Create a file called: 

index.html

The file called index.html is commonly used as the main page of a simple website.

03

Create Your CSS File

Create another file called: 

style.css

CSS controls the appearance of your website, including fonts, spacing, layouts and colors.

04

Create Your JavaScript File

Create: 

script.js

JavaScript can make your website interactive. For example, you can use it for menus, buttons and other website behavior.

05

Connect Your Files

In your HTML file, connect your CSS file inside the <head> section: 

<link rel="stylesheet" href="style.css">

Then connect JavaScript before the closing </body> tag: 

<script src="script.js"></script>
06

Preview Your Website

Save your files and use the preview feature in SPCK Editor to see how your website looks.

If something is not working, check your file names, spelling, HTML tags and file connections.

Example Project Structure 

MyWebsite/
│
├── index.html
├── style.css
└── script.js
