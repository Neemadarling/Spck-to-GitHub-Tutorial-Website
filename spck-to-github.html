From Your Phone to the Internet

You created your website in SPCK. Now it is time to publish it.

This guide explains the basic workflow for taking a static HTML, CSS and JavaScript website from your phone and publishing it with GitHub Pages.

01 Create website
↓
02 Test in SPCK
↓
03 Create GitHub repository
↓
04 Upload files
↓
05 Enable GitHub Pages
↓
06 Open your website
📱

STEP 01

Finish Your Website in SPCK

Before publishing, make sure your website works correctly inside SPCK.

Save all your files.

Example: 
MyWebsite/
│
├── index.html
├── about.html
├── tutorials.html
├── spck.html
├── html-tutorial.html
├── css-tutorial.html
├── javascript-tutorial.html
├── github.html
├── spck-to-github.html
├── style.css
└── script.js
🔍

STEP 02

Test Every Page

Preview your website in SPCK before uploading it.

Check your navigation links carefully.

✓ Home opens
✓ About opens
✓ Tutorials opens
✓ SPCK lesson opens
✓ HTML lesson opens
✓ CSS lesson opens
✓ JavaScript lesson opens
✓ GitHub lesson opens
✓ CSS styling appears
✓ Mobile menu works
🐙

STEP 03

Open GitHub

Open your phone browser and visit: 

https://github.com/

Sign in to your GitHub account.

💡 If you do not have a GitHub account, create one before continuing.
📦

STEP 04

Create a New Repository

From your GitHub account, choose the option to create a new repository.

Give your project a simple name, for example: 

neema-charo-website

Choose the visibility you want for the project. If you intend to use GitHub Pages for a public website, make sure the repository and Pages configuration meet GitHub's current requirements.

📤

STEP 05

Upload Your Website Files

Open your new repository and use GitHub's web interface to add/upload your website files.

Upload the HTML files, CSS file, JavaScript file and any images or other assets your website uses.

⚠️ Important: Do not upload only one HTML page if the other pages are linked from it. Upload the complete website project and preserve the correct file names and folder structure.
💾

STEP 06

Commit Your Changes

After adding your files, GitHub will ask you to commit the changes.

A commit message could be: 

Upload my first website

Then save/commit the changes to the repository.

⚙️

STEP 07

Open Repository Settings

Open the settings for your repository.

Look for the section related to: 

Pages

GitHub's interface can change over time, so the exact buttons or layout may look different from one version to another.

🌐

STEP 08

Configure GitHub Pages

In the GitHub Pages settings, select the publishing source available for your repository.

For a simple website stored in the repository's main branch, GitHub commonly provides a workflow where the Pages source is selected from a branch and folder.

Save the Pages configuration.

💡 GitHub may take a short time to build and publish your website after you save the settings.
🔗

STEP 09

Find Your Website Link

Once GitHub Pages has successfully published the site, GitHub will show the Pages website address in the repository's Pages area.

A typical project-site address looks similar to: 

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

Replace the username and repository name with your actual GitHub details.

🧪

STEP 10

Test the Live Website

Open the published address in your phone browser.

Test:

✓ Home page
✓ Navigation
✓ Buttons
✓ Images
✓ CSS
✓ JavaScript
✓ Mobile layout
🔄

STEP 11

Update Your Website Later

You don't have to create a new website every time you want to make a change.

Your normal workflow can be: 

Edit website in SPCK
        ↓
Save files
        ↓
Preview and test
        ↓
Upload the changed files to GitHub
        ↓
Commit changes
        ↓
GitHub Pages rebuilds
        ↓
Refresh your live website

TROUBLESHOOTING

Website Not Working?

❌ I see a 404 page

Check that your main file is named: 

index.html

Also check that your GitHub Pages source is configured correctly.

❌ My CSS is missing

Check that your HTML contains: 

<link rel="stylesheet"
      href="style.css">

Also make sure style.css was uploaded to the expected location.

❌ My JavaScript is not working

Check that your HTML contains: 

<script src="script.js">
</script>

Also make sure the JavaScript file was uploaded with the correct name and path.

❌ My links don't open

Check the spelling and capitalization of your filenames. 

about.html

About.html

ABOUT.html

These are not necessarily treated as the same path on web hosting.

❌ My image doesn't appear

Check the image path in your HTML. 

<img src="images/photo.jpg"
     alt="My photo">

Make sure the image exists in the matching folder in your repository.
