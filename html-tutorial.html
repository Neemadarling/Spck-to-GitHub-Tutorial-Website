LESSON 02

HTML for Beginners

Learn how to build the structure of a website.

🧱

What is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create the structure and content of a webpage.

Think of HTML as the skeleton of a website. CSS will later make the skeleton look beautiful.

01

Basic HTML Structure

A basic HTML document can look like this: 

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

</head>

<body>

    <h1>Hello World!</h1>

    <p>
        Welcome to my website.
    </p>

</body>

</html>
💡 Remember: Most visible webpage content goes inside the <body>.
02

Headings

HTML provides six levels of headings: 

<h1>Main Heading</h1>

<h2>Second Heading</h2>

<h3>Third Heading</h3>

<h4>Fourth Heading</h4>

<h5>Fifth Heading</h5>

<h6>Sixth Heading</h6>

Usually, <h1> represents the main heading of a page.

03

Paragraphs

Use the paragraph element to write text: 

<p>
I am learning how to create websites.
</p>
04

Links

Links allow visitors to move from one page or website to another. 

<a href="https://github.com">
Visit GitHub
</a>

You can also link to another page inside your own website: 

<a href="about.html">
About Me
</a>
05

Images

Images can be added using the <img> element. 

<img src="my-photo.jpg"
     alt="My photo">
💡 Tip: If the image is inside your project folder, make sure the file name and path are correct.
06

Buttons

You can create a button using: 

<button>
Click Me
</button>

JavaScript can later be used to make the button perform an action.

07

Lists

An unordered list: 

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

An ordered list: 

<ol>

    <li>Create your files</li>

    <li>Write your code</li>

    <li>Preview your website</li>

</ol>
08

Divs and Sections

A <div> can be used as a container for content. 

<div>

    <h2>About Me</h2>

    <p>
        Welcome to my website.
    </p>

</div>

HTML also provides semantic elements such as <header>, <nav>, <main>, <section> and <footer>.

09

Forms

Forms allow visitors to enter information. 

<form>

    <label>
        Your Name
    </label>

    <input
        type="text"
        placeholder="Enter your name">

    <button type="submit">
        Send
    </button>

</form>
10

HTML Attributes

Attributes provide additional information about an HTML element. 

<a href="about.html">
About
</a>

<img
    src="photo.jpg"
    alt="My photo">

In the first example, href tells the browser where the link should go.

In the second example, src identifies the image and alt provides alternative text.
