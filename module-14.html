MODULE 14

🎓 Final Website Project

Bring everything you have learned together and build your own complete website.

YOUR FINAL PROJECT

🚀 Build a Complete Website

You will now create a website from beginning to end.

Choose a real or fictional business, service, personal brand or portfolio.

1. Plan Your Website

Decide:

  • Website name
  • Purpose
  • Target audience
  • Pages
  • Colors
  • Typography
  • Content

2. Create Your Files

index.html
about.html
services.html
portfolio.html
contact.html
style.css
script.js

3. Build the HTML

Create the structure of every page.

Make sure your pages have:

  • Header
  • Navigation
  • Main content
  • Sections
  • Footer

4. Design With CSS

Make the website:

  • Beautiful
  • Readable
  • Consistent
  • Mobile-friendly
  • Easy to navigate

5. Add JavaScript

Add at least one useful interactive feature.

For example:

  • Mobile menu
  • Interactive button
  • Form interaction
  • Simple calculator
  • Message display

6. Add Images and Links

Use appropriate images and make sure all links work.

7. Test Your Website

Check every page on your phone.

  • Links
  • Buttons
  • Images
  • Text
  • Spacing
  • Responsive design

8. Publish Your Website

Upload your final project to GitHub and publish it using GitHub Pages or another suitable hosting service.

🏆 Final Project Checklist

  1. My website has a clear purpose.
  2. My navigation works.
  3. My pages are connected.
  4. My images work.
  5. My CSS works.
  6. My JavaScript works.
  7. My website works on mobile.
  8. My website is published.
  9. I have tested the live website.

SUBMISSION

📤 Submit Your Project

Prepare your live website link for the final assessment.

Make sure the link opens correctly before submitting it.

🎉 Final Project Complete!

You have brought together the skills learned throughout the course.

Next comes the final assessment and certificate.
