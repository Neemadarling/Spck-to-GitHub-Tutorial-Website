MODULE 02

📝 HTML — Build Your Website Structure

Learn the language that gives a website its structure and content.

TOPIC 01

What Is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create the structure and content of a webpage.

Think of HTML as the building blocks of a website. Before we decorate a house, we first build its structure. HTML does the same thing for a website.

📝 HTML = Website structure

🎨 CSS = Website design

⚡ JavaScript = Website interaction

TOPIC 02

Your First HTML Document

A normal HTML document begins with a basic structure like this: 

<!DOCTYPE html>

<html>

<head>

    <title>My Website</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first webpage.</p>

</body>

</html>

Don't worry if this looks unfamiliar. We will understand every part step by step.

TOPIC 03

HTML Headings

Headings are used for titles and important sections of your webpage. 

<h1>Main Website Title</h1>

<h2>About Me</h2>

<h3>My Skills</h3>

<h4>Website Design</h4>

HTML provides headings from h1 to h6.

Usually, your main page title should use h1, while smaller sections can use h2, h3 and so on.

TOPIC 04

Paragraphs

Paragraphs contain normal text on your webpage. 

<p>
    Welcome to my website.
</p>

You can create as many paragraphs as your page needs.

TOPIC 05

Links

Links allow visitors to move from one webpage to another. 

<a href="about.html">
    About Me
</a>

The href tells the browser where the link should go.

You can also link to another website: 

<a href="https://www.google.com">
    Visit Google
</a>

TOPIC 06

Images

Images make websites more useful and attractive. 

<img src="profile.jpg"
     alt="My profile photo">

The src tells the browser where the image is located.

The alt describes the image and is important for accessibility.

💡 Keep your image inside your project folder when using a local image.

TOPIC 07

Lists

HTML can create ordered and unordered lists.

Unordered List 

<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

Ordered List 

<ol>

    <li>Learn HTML</li>

    <li>Learn CSS</li>

    <li>Learn JavaScript</li>

</ol>

TOPIC 08

Buttons

Buttons are commonly used for actions on websites. 

<button>
    Click Me
</button>

Later, we will use JavaScript to make buttons perform different actions.

TOPIC 09

Forms

Forms allow visitors to enter information. 

<form>

    <label>
        Name
    </label>

    <input type="text"
           placeholder="Enter your name">

    <button type="submit">
        Send
    </button>

</form>

Forms are commonly used for contact, registration and login pages.

TOPIC 10

Semantic HTML

Semantic HTML uses meaningful elements to describe different parts of a webpage. 

<header>

    Website Header

</header>


<nav>

    Navigation Links

</nav>


<main>

    Main Content

</main>


<section>

    Website Section

</section>


<footer>

    Website Footer

</footer>

Using meaningful HTML makes your website easier to understand and can improve accessibility.

PRACTICAL PROJECT

🛠️ Build Your First HTML Page

Now it's time to practice. Create a new HTML file in SPCK called: 

my-first-page.html

Then create a simple page containing:

  1. A main heading with your name
  2. A paragraph introducing yourself
  3. A list of your skills or interests
  4. A picture
  5. A link
  6. A button

Don't worry about making it beautiful yet. We will make it beautiful when we learn CSS.

EXAMPLE

Complete Beginner HTML Page 

<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width,
                   initial-scale=1.0">

    <title>My First Website</title>

</head>


<body>

    <header>

        <h1>
            Neema's Website
        </h1>

    </header>


    <main>

        <h2>
            About Me
        </h2>

        <p>
            Hello! I am learning website development.
        </p>


        <h2>
            My Skills
        </h2>

        <ul>

            <li>HTML</li>

            <li>Website Design</li>

            <li>Learning JavaScript</li>

        </ul>


        <a href="https://github.com">
            Visit GitHub
        </a>

    </main>


    <footer>

        <p>
            © My First Website
        </p>

    </footer>

</body>

</html>
