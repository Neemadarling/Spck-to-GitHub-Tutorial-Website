FREE BEGINNER LESSON • 03

CSS for Beginners

Learn how to style your website, create beautiful layouts and make your pages responsive.

🎨

What is CSS?

CSS stands for Cascading Style Sheets.

CSS controls how your HTML website looks. It can control colors, fonts, spacing, layouts, borders, animations and much more.

If HTML is the skeleton of your website, CSS is the design that makes it look attractive and professional.

01

How to Connect CSS

Create a file called: 

style.css

Then connect it to your HTML: 

<link rel="stylesheet" href="style.css">

Put this inside the <head> section.

02

Change Text Color

CSS can change the color of text. 

h1 {
color: purple;

}

You can use color names, HEX values, RGB and other CSS color formats.

03

Change Background Color 

body {
background-color: white;

}

.hero {
background-color: black;
}

The background can belong to the entire page or to a specific section.

04

Change Font Size 

h1 {
font-size: 50px;

}

p {
font-size: 18px;
}

Font size determines how large or small your text appears.

05

Margin and Padding

These properties are very important when designing websites. 

.card {
margin: 20px;
padding: 30px;

}

Margin creates space outside an element.

Padding creates space inside an element.

06

Borders and Rounded Corners 

.card {
border: 1px solid #dddddd;
border-radius: 20px;

}

border-radius is useful for creating modern rounded cards and buttons.

07

Box Shadow

Box shadows can give cards depth. 

.card {
box-shadow:
    0 10px 30px
    rgba(0, 0, 0, 0.10);

}
08

Flexbox

Flexbox is useful for arranging elements in rows or columns. 

.container {
display: flex;

justify-content: center;

align-items: center;

gap: 20px;

}

Flexbox is especially useful for navigation bars, buttons and layouts.

09

CSS Grid

Grid is excellent for creating rows and columns of cards. 

.cards {
display: grid;

grid-template-columns:
    repeat(3, 1fr);

gap: 20px;

}

This technique is useful for modern responsive layouts.

10

Hover Effects

CSS can make an element change when someone places their pointer over it. 

.card {
transition: 0.3s;

}

.card:hover {
transform: translateY(-8px);
}

Hover effects can make a website feel more interactive.

11

CSS Animations

CSS can also create animations. 

@keyframes float {

0% {
    transform: translateY(0);
}

50% {
    transform: translateY(-10px);
}

100% {
    transform: translateY(0);
}

}

.box {
animation:
float 3s infinite;
}

Animations can be used for subtle movement, entrances and visual effects.

12

Responsive Design

A responsive website adjusts to different screen sizes such as phones, tablets and computers. 

@media (max-width: 600px) {

.cards {
    grid-template-columns: 1fr;
}

h1 {
    font-size: 35px;
}

}
📱 Important: Always test your website on a phone because many visitors may access it from mobile devices.
13

CSS Classes and IDs

A class can be reused on multiple elements. 

.card {
padding: 20px;

}

An ID normally identifies one specific element. 

#main-title {
font-size: 50px;

}

  • A box shadow
