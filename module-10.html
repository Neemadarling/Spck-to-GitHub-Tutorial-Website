MODULE 10

🐙 GitHub & GitHub Pages

Learn how to store your website project online using GitHub.

TOPIC 01

What Is GitHub?

GitHub is a platform where developers can store, manage and share code projects.

For our website projects, GitHub can also help us publish websites using GitHub Pages.

TOPIC 02

Create a GitHub Account

Visit: 

https://github.com

Create an account and verify your email if required.

TOPIC 03

Create a Repository

A repository is a project space where your website files can be stored.

Give your repository a clear name such as: 

my-website

TOPIC 04

Upload Your Website Files

Upload your HTML, CSS, JavaScript and image files to your repository.

Make sure your main homepage is normally named: 

index.html

TOPIC 05

Using SPCK With GitHub

You can connect SPCK to GitHub and push your project from your phone.

Always make sure your GitHub token has the permissions needed for the repository operation you are performing.

TOPIC 06

GitHub Pages

GitHub Pages can host static websites directly from a GitHub repository.

In your repository, look for the Pages settings and select the appropriate publishing source.

PRACTICAL PROJECT

🛠️ Upload Your Website

  1. Create a GitHub repository.
  2. Upload your website files.
  3. Check that index.html exists.
  4. Open the repository settings.
  5. Find Pages.
  6. Configure your publishing source.
