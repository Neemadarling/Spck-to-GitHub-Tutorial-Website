MODULE 03

🎨 CSS — Design & Responsive Websites

Learn how to transform plain HTML into beautiful, professional and mobile-friendly websites.

TOPIC 01

What Is CSS?

CSS stands for Cascading Style Sheets.

CSS controls how your HTML website looks. It allows you to change colors, fonts, spacing, layouts, borders, backgrounds and much more.

📝 HTML = Structure

🎨 CSS = Appearance

⚡ JavaScript = Interaction

TOPIC 02

How to Add CSS

There are three common ways to add CSS. In this course, we will mainly use an external CSS file.

External CSS 

<link rel="stylesheet"
      href="style.css">

This connects your HTML page to a file called style.css.

Keeping your CSS in a separate file makes your project easier to organize and maintain.

TOPIC 03

CSS Selectors

A selector tells CSS which HTML element you want to style.

Element Selector 

h1 {
    color: blue;
}

Class Selector 

.title {
    color: blue;
}

ID Selector 

#main-title {
    color: blue;
}

Classes are especially useful when you want to apply the same design to several elements.

TOPIC 04

Colors

CSS allows you to control the color of text, backgrounds and other elements. 

body {
    background-color: white;
}

h1 {
    color: black;
}

p {
    color: #555;
}

Colors can be written using names, hexadecimal values, RGB and other formats.

TOPIC 05

Fonts and Text

You can control how your text looks using CSS properties. 

h1 {
    font-size: 40px;
    font-weight: 700;
}

p {
    font-size: 18px;
    line-height: 1.6;
}

Common text properties include:

  • font-size
  • font-weight
  • line-height
  • text-align
  • letter-spacing

TOPIC 06

Spacing

Good spacing makes a website easier to read and more professional.

Margin

Margin creates space outside an element. 

h1 {
    margin-bottom: 20px;
}

Padding

Padding creates space inside an element. 

.card {
    padding: 20px;
}

💡 Easy way to remember:

Padding = inside

Margin = outside

TOPIC 07

Width, Height and Borders 

.card {
    width: 300px;
    min-height: 200px;
    border: 1px solid #ddd;
    border-radius: 12px;
}

Borders can help separate sections and create cards, boxes and buttons.

TOPIC 08

Flexbox

Flexbox is one of the most useful CSS layout systems.

It makes it easier to arrange elements horizontally or vertically. 

.container {
    display: flex;
    gap: 20px;
    justify-content: center;
    align-items: center;
}

You can use Flexbox to create navigation bars, rows, cards and many other layouts.

TOPIC 09

CSS Grid

CSS Grid is useful when you want to create structured rows and columns. 

.cards {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
    gap: 20px;
}

Grid is especially useful for portfolios, course cards, product sections and galleries.

TOPIC 10

Buttons and Cards

Professional websites often use cards and buttons to organize information. 

.card {
    padding: 25px;
    border-radius: 15px;
    box-shadow: 0 5px 20px
                rgba(0, 0, 0, 0.08);
}

.button {
    display: inline-block;
    padding: 12px 20px;
    border-radius: 8px;
    text-decoration: none;
}

TOPIC 11

Responsive Design

A responsive website automatically adjusts to different screen sizes.

This is especially important because many people access websites using smartphones.

Media Queries 

@media (max-width: 768px) {

    .cards {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 30px;
    }

}

A media query allows you to change your design when the screen becomes smaller.

TOPIC 12

The CSS Box Model

Every HTML element can be thought of as a box.

📦 Content

↔️ Padding

🔲 Border

↔️ Margin

Understanding the box model will help you control spacing and layouts much more easily.

EXAMPLE PROJECT

Simple CSS Website

Try this CSS with the HTML from Module 02: 

* {
    box-sizing: border-box;
}

    background: #f5f5f5;
    color: #222;

    max-width: 900px;
    margin: auto;
    padding: 40px 20px;
}

.card {
    background: white;
    padding: 30px;
    border-radius: 15px;
    box-shadow:
        0 5px 20px
        rgba(0, 0, 0, 0.08);
}

    font-size: 40px;
    margin-bottom: 15px;
}

    line-height: 1.6;
}

    display: inline-block;
    margin-top: 15px;
    padding: 12px 20px;
    text-decoration: none;
    border-radius: 8px;
}

    main {
        padding: 25px 15px;
    }

    h1 {
        font-size: 30px;
    }

    .card {
        padding: 20px;
    }

}
