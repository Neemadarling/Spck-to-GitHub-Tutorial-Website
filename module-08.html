MODULE 08

🖼️ Images, Links, Pages & Navigation

Learn how to connect pages and add images to your website.

TOPIC 01

Adding Images

<img
    src="images/photo.jpg"
    alt="My photo">

The src tells the browser where the image is located.

The alt describes the image.

TOPIC 02

Creating Links

<a href="about.html">
    About Me
</a>

TOPIC 03

Creating Multiple Pages

A website can have several HTML pages. 

index.html
about.html
services.html
portfolio.html
contact.html

TOPIC 04

Navigation Menus

<nav>

    <a href="index.html">Home</a>

    <a href="about.html">About</a>

    <a href="services.html">Services</a>

    <a href="contact.html">Contact</a>

</nav>

TOPIC 05

External Links

<a
href="https://example.com"
target="_blank"
rel="noopener">

Visit Website

</a>

TOPIC 06

Email and Phone Links

<a href="mailto:hello@example.com">
Email Me
</a>

<a href="tel:+254700000000">
Call Me
</a>
